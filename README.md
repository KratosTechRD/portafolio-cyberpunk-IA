## 🎯 Objetivo del Proyecto
Diseñar, generar mediante *Prompt Engineering* asistido por Inteligencia Artificial y desplegar un portafolio web profesional con estética Cyberpunk programado íntegramente en un único archivo `index.html`. El proyecto incorpora un fondo animado estilo "Matrix" mediante `<canvas>` en JavaScript, selector de tema Oscuro/Claro con contraste garantizado al 100%, filtros dinámicos para 9 proyectos, sección de experiencia laboral, galería de videos formativos de YouTube y formulario de contacto funcional.

## 🛠️ Tecnologías Utilizadas
* **HTML5 Semántico:** Estructura completa y optimizada para SEO y accesibilidad en un solo archivo (`index.html`).
* **CSS3 & Variables Dinámicas:** Paleta neón Cyberpunk y sistema de temas `Dark/Light` con contraste absoluto garantizado.
* **Bootstrap 5.3:** Diseño 100% responsivo (*Mobile-First*) para móviles, tablets y escritorio.
* **JavaScript (ES6+):** Lluvia digital Matrix en `<canvas>` (`position: fixed; z-index: -1`), filtrado dinámico por categorías (`Web`, `App`, `Diseño`) e interactividad del DOM.
* **Devicon & Bootstrap Icons:** Íconos oficiales de cada tecnología del perfil y redes sociales.
* **EmailJS / FormSubmit:** Envío de mensajes directamente desde el frontend hacia el correo electrónico.

## 🆚 Comparación de Despliegue: GitHub Pages vs. Vercel

| Criterio | GitHub Pages | Vercel |
| :--- | :--- | :--- |
| **Enfoque Principal** | Hosting gratuito de sitios estáticos integrado directamente en el repositorio de GitHub. | Plataforma Cloud optimizada para Frontend, sitios estáticos y despliegue continuo (CI/CD). |
| **Velocidad de Despliegue** | Media (1 a 3 minutos en procesar y publicar cada cambio). | Ultrarrápida (desplegado en **4 segundos** en pruebas reales tras importar el repositorio). |
| **Entornos de Prueba (Preview)** | Publica únicamente la rama principal configurada (`main`). | Genera URLs de previsualización automáticas por cada *commit* o rama. |
| **Facilidad de Uso** | Se activa en `Settings > Pages` seleccionando la rama `main` y carpeta `/(root)`. | Se conecta con GitHub en 1 clic (`Import > Deploy`) detectando la configuración automáticamente. |
