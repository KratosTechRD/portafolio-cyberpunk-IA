## 🎯 Objetivo del Proyecto
Diseñar, generar con asistencia de Inteligencia Artificial y desplegar un portafolio web profesional con estética Cyberpunk en un único archivo `index.html`. El proyecto integra un fondo animado estilo "Matrix" mediante HTML5 `<canvas>`, selector de tema Oscuro/Claro con contraste garantizado al 100%, filtros dinámicos de proyectos por categoría, galería de videos formativos y formulario de contacto funcional.

## 🛠️ Tecnologías Utilizadas
* **HTML5 Semántico:** Estructura integral en un único documento (`index.html`).
* **CSS3 & Variables Dinámicas:** Paleta neón Cyberpunk y cambio de tema `dark`/`light` con contraste de lectura garantizado.
* **Bootstrap 5.3:** Sistema de rejilla responsiva (*Mobile-First*).
* **JavaScript (ES6+):** Animación Matrix en `<canvas>`, filtrado dinámico de las 9 tarjetas de proyectos (Web, App, Diseño) y control del DOM.
* **Devicon & Bootstrap Icons:** Iconografía oficial del stack tecnológico.
* **EmailJS / FormSubmit:** Integración para recepción de correos desde el formulario de contacto.

## 🆚 Comparación de Despliegue: GitHub Pages vs. Vercel

| Criterio | GitHub Pages | Vercel |
| :--- | :--- | :--- |
| **Enfoque Principal** | Alojamiento de sitios estáticos directamente desde repositorios de GitHub. | Plataforma Cloud para Frontend, aplicaciones Serverless, SSR y sitios estáticos. |
| **Velocidad de Despliegue** | Media (1 a 3 minutos mediante GitHub Actions). | Muy alta (15 a 40 segundos en red Edge global). |
| **Entornos de Prueba (Preview)** | No genera URLs previas automáticas por cada *Pull Request* de forma nativa. | Genera una URL única de previsualización por cada *commit* o *Pull Request*. |
| **Configuración Inicial** | Integrada dentro del mismo repositorio (`Settings > Pages`). | Requiere conectar la cuenta de GitHub a la plataforma externa de Vercel. |
| **Ideal para este proyecto** | Excelente por centralizar código, documentación y hosting en un solo lugar académico. | Excelente cuando se requiere analítica en tiempo real, funciones serverless o CI/CD avanzado. |
